# Стенд Arduino Nano и 74HC4075

Временная проверка физической микросхемы. Перед merge request этот каталог удаляется.

Цоколёвка — Nexperia 74HC4075/74HCT4075, Rev. 6 (21 марта 2024). У 74HC и 74HCT одинаковые функция и номера выводов: вывод 7 это GND, вывод 14 это VCC. В даташите корпус SO14; в более ранних ревизиях те же выводы есть у SSOP14 и TSSOP14. Это не DIP. Для макетной платы нужен переходник. Перед подачей питания сверить маркировку и убедиться, что вывод 7 соединён с GND.

Nano работает от 5 В. D0 и D1 заняты Serial (115200) и к микросхеме не подключаются. Между выводами 14 и 7, рядом с корпусом, поставить конденсатор 100 нФ. Входы CMOS нельзя оставлять висящими: все девять входов приходят с Nano. Выходы двухтактные, последовательные резисторы не нужны.

Точка или выемка на корпусе отмечает сторону вывода 1. Ниже нумерация сверху, от выемки вниз по левому ряду и вверх по правому.

- Вывод 1, 2A — D2, выход Nano
- Вывод 2, 2B — D3, выход Nano
- Вывод 3, 1A — D4, выход Nano
- Вывод 4, 1B — D5, выход Nano
- Вывод 5, 1C — D6, выход Nano
- Вывод 6, 1Y — D11, вход Nano
- Вывод 7, GND — GND Nano, питание
- Вывод 8, 2C — D7, выход Nano
- Вывод 9, 2Y — D12, вход Nano
- Вывод 10, 3Y — D13, вход Nano
- Вывод 11, 3A — D8, выход Nano
- Вывод 12, 3B — D9, выход Nano
- Вывод 13, 3C — D10, выход Nano
- Вывод 14, VCC — 5V Nano, питание

D13 подключён к 3Y, поэтому светодиод платы загорается, когда этот выход в HIGH.

Каждый выход повторяет ИЛИ трёх своих входов: 1Y = 1A | 1B | 1C, 2Y = 2A | 2B | 2C, 3Y = 3A | 3B | 3C. Выход LOW только когда все три входа LOW.

Скетч `ttl744075_nano/ttl744075_nano.ino` после сброса ждёт любой символ из Serial Monitor. Он перебирает все 512 комбинаций девяти входов и сверяет три выхода. Успех — последняя строка `RESULT PASS`. Первое расхождение печатается как `RESULT FAIL` и дальше не затирается. Повторный символ запускает проверку ещё раз.
