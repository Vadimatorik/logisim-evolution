# Стенд Arduino Nano и 74HC4020

Временная проверка физической микросхемы. Перед merge request этот каталог удаляется.

Цоколёвка — TI CD74HC4020 и Nexperia 74HC4020. Номера выводов DIP-16, SO16 и TSSOP16 совпадают: вывод 8 это GND, вывод 16 это VCC. Имена выходов ниже — как у TI: `Qn` делит такт на `2^n`, `Q1` младший. У Nexperia те же выводы названы на единицу меньше (`Q0` и `Q3`…`Q13`). `Q2` и `Q3` на корпус не выведены, но участвуют в счёте. Если корпус не DIP, для макетной платы нужен переходник. Перед подачей питания сверить маркировку и убедиться, что вывод 8 соединён с GND.

Nano работает от 5 В. D0 и D1 заняты Serial (115200) и к микросхеме не подключаются. A6 и A7 у ATmega328P только аналоговые, как цифровые их использовать нельзя. Между выводами 16 и 8, рядом с корпусом, поставить конденсатор 100 нФ. Входы CMOS нельзя оставлять висящими: CP и MR приходят с Nano. Выходы всегда активны, последовательные резисторы не нужны.

Точка или выемка на корпусе отмечает сторону вывода 1. Ниже нумерация сверху, от выемки вниз по левому ряду и вверх по правому.

- Вывод 1, Q12 (Nexperia Q11) — D13, вход Nano
- Вывод 2, Q13 (Nexperia Q12) — A0, вход Nano
- Вывод 3, Q14 (Nexperia Q13) — A1, вход Nano
- Вывод 4, Q6 (Nexperia Q5) — D7, вход Nano
- Вывод 5, Q5 (Nexperia Q4) — D6, вход Nano
- Вывод 6, Q7 (Nexperia Q6) — D8, вход Nano
- Вывод 7, Q4 (Nexperia Q3) — D5, вход Nano
- Вывод 8, GND — GND Nano, питание
- Вывод 9, Q1 (Nexperia Q0) — D4, вход Nano
- Вывод 10, CP — D2, выход Nano
- Вывод 11, MR — D3, выход Nano
- Вывод 12, Q9 (Nexperia Q8) — D10, вход Nano
- Вывод 13, Q8 (Nexperia Q7) — D9, вход Nano
- Вывод 14, Q10 (Nexperia Q9) — D11, вход Nano
- Вывод 15, Q11 (Nexperia Q10) — D12, вход Nano
- Вывод 16, VCC — 5V Nano, питание

D13 подключён к Q12, поэтому светодиод платы загорается, когда этот разряд в HIGH.

Высокий MR сбрасывает все выходы в LOW независимо от CP. При низком MR спад CP увеличивает код на 1 по модулю 16384. Фронт CP код не меняет. Скетч сравнивает только выведенные разряды: Q1 и Q4…Q14.

Скетч `ttl744020_nano/ttl744020_nano.ino` после сброса ждёт любой символ из Serial Monitor. Он проверяет удержание нуля при высоком MR, отсутствие шага по фронту CP, шаг по спаду, все 16384 состояния и переход 16383→0, затем повторный сброс посреди счёта. Успех — последняя строка `RESULT PASS`. Первое расхождение печатается как `RESULT FAIL` и дальше не затирается. Повторный символ запускает проверку ещё раз.
