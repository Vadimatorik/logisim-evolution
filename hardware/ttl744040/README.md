# Стенд Arduino Nano и 74HC4040

Временная проверка физической микросхемы. Перед merge request этот каталог удаляется.

Цоколёвка — TI SN74HC4040 и Nexperia 74HC4040. Номера выводов DIP-16, SO16 и TSSOP16 совпадают: вывод 8 это GND, вывод 16 это VCC. Имена выходов ниже — как у TI: `Qn` делит такт на `2^n`, `Q1` младший. У Nexperia те же выводы названы на единицу меньше (`Q0`…`Q11`). Если корпус не DIP, для макетной платы нужен переходник. Перед подачей питания сверить маркировку и убедиться, что вывод 8 соединён с GND.

Nano работает от 5 В. D0 и D1 заняты Serial (115200) и к микросхеме не подключаются. A6 и A7 у ATmega328P только аналоговые, как цифровые их использовать нельзя. Между выводами 16 и 8, рядом с корпусом, поставить конденсатор 100 нФ. Входы CMOS нельзя оставлять висящими: CP и MR приходят с Nano. Выходы всегда активны, последовательные резисторы не нужны.

Точка или выемка на корпусе отмечает сторону вывода 1. Ниже нумерация сверху, от выемки вниз по левому ряду и вверх по правому.

- Вывод 1, Q12 (Nexperia Q11) — A1, вход Nano
- Вывод 2, Q6 (Nexperia Q5) — D9, вход Nano
- Вывод 3, Q5 (Nexperia Q4) — D8, вход Nano
- Вывод 4, Q7 (Nexperia Q6) — D10, вход Nano
- Вывод 5, Q4 (Nexperia Q3) — D7, вход Nano
- Вывод 6, Q3 (Nexperia Q2) — D6, вход Nano
- Вывод 7, Q2 (Nexperia Q1) — D5, вход Nano
- Вывод 8, GND — GND Nano, питание
- Вывод 9, Q1 (Nexperia Q0) — D4, вход Nano
- Вывод 10, CP — D2, выход Nano
- Вывод 11, MR — D3, выход Nano
- Вывод 12, Q9 (Nexperia Q8) — D12, вход Nano
- Вывод 13, Q8 (Nexperia Q7) — D11, вход Nano
- Вывод 14, Q10 (Nexperia Q9) — D13, вход Nano
- Вывод 15, Q11 (Nexperia Q10) — A0, вход Nano
- Вывод 16, VCC — 5V Nano, питание

D13 подключён к Q10, поэтому светодиод платы загорается, когда этот разряд в HIGH.

Высокий MR сбрасывает все выходы в LOW независимо от CP. При низком MR спад CP увеличивает код на 1 по модулю 4096. Фронт CP код не меняет.

Скетч `ttl744040_nano/ttl744040_nano.ino` после сброса ждёт любой символ из Serial Monitor. Он проверяет удержание нуля при высоком MR, отсутствие шага по фронту CP, шаг по спаду, все 4096 состояний и переход 4095→0, затем повторный сброс посреди счёта. Успех — последняя строка `RESULT PASS`. Первое расхождение печатается как `RESULT FAIL` и дальше не затирается. Повторный символ запускает проверку ещё раз.
