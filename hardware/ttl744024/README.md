# Стенд Arduino Nano и 74HC4024

Временная проверка физической микросхемы. Перед merge request этот каталог удаляется.

Цоколёвка — TI CD74HC4024 и Nexperia 74HC4024. Номера выводов DIP-14, SO14 и TSSOP14 совпадают: вывод 7 это GND, вывод 14 это VCC. Выводы 8, 10 и 13 не подключены. Имена выходов ниже — как у TI: `Qn` делит такт на `2^n`, `Q1` младший. У Nexperia те же выводы названы на единицу меньше (`Q0`…`Q6`). Если корпус не DIP, для макетной платы нужен переходник. Перед подачей питания сверить маркировку и убедиться, что вывод 7 соединён с GND.

Nano работает от 5 В. D0 и D1 заняты Serial (115200) и к микросхеме не подключаются. A6 и A7 у ATmega328P только аналоговые, как цифровые их использовать нельзя. Между выводами 14 и 7, рядом с корпусом, поставить конденсатор 100 нФ. Входы CMOS нельзя оставлять висящими: CP и MR приходят с Nano. Выходы всегда активны, последовательные резисторы не нужны.

Точка или выемка на корпусе отмечает сторону вывода 1. Ниже нумерация сверху, от выемки вниз по левому ряду и вверх по правому.

- Вывод 1, CP — D2, выход Nano
- Вывод 2, MR — D3, выход Nano
- Вывод 3, Q7 (Nexperia Q6) — D13, вход Nano
- Вывод 4, Q6 (Nexperia Q5) — D9, вход Nano
- Вывод 5, Q5 (Nexperia Q4) — D8, вход Nano
- Вывод 6, Q4 (Nexperia Q3) — D7, вход Nano
- Вывод 7, GND — GND Nano, питание
- Вывод 8, n.c. — не подключать
- Вывод 9, Q3 (Nexperia Q2) — D6, вход Nano
- Вывод 10, n.c. — не подключать
- Вывод 11, Q2 (Nexperia Q1) — D5, вход Nano
- Вывод 12, Q1 (Nexperia Q0) — D4, вход Nano
- Вывод 13, n.c. — не подключать
- Вывод 14, VCC — 5V Nano, питание

D13 подключён к Q7, поэтому светодиод платы загорается, когда старший разряд в HIGH.

Высокий MR сбрасывает все выходы в LOW независимо от CP. При низком MR спад CP увеличивает код на 1 по модулю 128. Фронт CP код не меняет.

Скетч `ttl744024_nano/ttl744024_nano.ino` после сброса ждёт любой символ из Serial Monitor. Он проверяет удержание нуля при высоком MR, отсутствие шага по фронту CP, шаг по спаду, все 128 состояний и переход 127→0, затем повторный сброс посреди счёта. Успех — последняя строка `RESULT PASS`. Первое расхождение печатается как `RESULT FAIL` и дальше не затирается. Повторный символ запускает проверку ещё раз.
