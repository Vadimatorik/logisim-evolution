# Стенд Arduino Nano и 74HC257

Временная проверка физической микросхемы. Перед merge request этот каталог удаляется.

Цоколёвка — Nexperia 74HC257 и TI SN74HC257. У DIP-16, SO16 и TSSOP16 номера выводов совпадают: вывод 8 это GND, вывод 16 это VCC. Если корпус не DIP, для макетной платы нужен переходник. Перед подачей питания сверить маркировку и убедиться, что вывод 8 соединён с GND.

Nano работает от 5 В. D0 и D1 заняты Serial (115200) и к микросхеме не подключаются. A6 и A7 у ATmega328P только аналоговые, как цифровые их использовать нельзя. Между выводами 16 и 8, рядом с корпусом, поставить конденсатор 100 нФ. Входы CMOS нельзя оставлять висящими: все десять приходят с Nano.

Между каждым выходом `1Y`–`4Y` и входом Nano стоит резистор 470 Ом. Скетч на короткое время прижимает свой вход к земле, чтобы отличить высокий уровень от третьего состояния, и резистор ограничивает ток этого опроса.

Точка или выемка на корпусе отмечает сторону вывода 1. Ниже нумерация сверху, от выемки вниз по левому ряду и вверх по правому.

- Вывод 1, S — D2, выход Nano
- Вывод 2, 1I0 — D3, выход Nano
- Вывод 3, 1I1 — D4, выход Nano
- Вывод 4, 1Y — D12, вход Nano, через 470 Ом
- Вывод 5, 2I0 — D5, выход Nano
- Вывод 6, 2I1 — D6, выход Nano
- Вывод 7, 2Y — D13, вход Nano, через 470 Ом
- Вывод 8, GND — GND Nano, питание
- Вывод 9, 3Y — A0, вход Nano, через 470 Ом
- Вывод 10, 3I1 — D8, выход Nano
- Вывод 11, 3I0 — D7, выход Nano
- Вывод 12, 4Y — A1, вход Nano, через 470 Ом
- Вывод 13, 4I1 — D10, выход Nano
- Вывод 14, 4I0 — D9, выход Nano
- Вывод 15, nOE — D11, выход Nano
- Вывод 16, VCC — 5V Nano, питание

D13 подключён к `2Y`, поэтому светодиод платы повторяет второй выход, пока он не в третьем состоянии.

`nOE` в HIGH отпускает все четыре выхода в Z. `nOE` в LOW пропускает выбранный источник без инверсии: при `S` в LOW выход повторяет `nI0`, при `S` в HIGH — `nI1`. Невыбранный вход на выход не влияет.

Опрос выхода: сначала чтение с внутренней подтяжкой к питанию, затем краткий разряд входа Nano в LOW и чтение без подтяжки. Оба нуля — выход прижат к 0, обе единицы — к 1, единица затем ноль — Z.

Скетч `ttl74257_nano/ttl74257_nano.ino` после сброса ждёт любой символ из Serial Monitor. Он проверяет Z при высоком `nOE` и передачу выбранного источника при низком, для обоих уровней `S` и всех сочетаний четырёх бит. Успех — последняя строка `RESULT PASS`. Первое расхождение печатается как `RESULT FAIL` и дальше не затирается. Повторный символ запускает проверку ещё раз.
