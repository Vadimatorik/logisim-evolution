# Стенд Arduino Nano и 74HC195

Временная проверка физической микросхемы. Перед merge request этот каталог удаляется.

Цоколёвка — TI CD74HC195 и Philips 74HC/HCT195. У DIP-16, SO16 и TSSOP16 номера выводов совпадают: вывод 8 это GND, вывод 16 это VCC. Если корпус не DIP, для макетной платы нужен переходник. Перед подачей питания сверить маркировку и убедиться, что вывод 8 соединён с GND.

Это не цоколёвка 74LS195. У LS такт на выводе 15, а инверсия последнего разряда на выводе 10. У HC такт на выводе 10, инверсия `Q3` на выводе 11, а `Q0` на выводе 15.

Nano работает от 5 В. D0 и D1 заняты Serial (115200) и к микросхеме не подключаются. A6 и A7 у ATmega328P только аналоговые, как цифровые их использовать нельзя. Между выводами 16 и 8, рядом с корпусом, поставить конденсатор 100 нФ. Внешние подтяжки не нужны: входы CMOS нельзя оставлять висящими, все они приходят с Nano, выходы двухтактные.

Точка или выемка на корпусе отмечает сторону вывода 1. Ниже нумерация сверху, от выемки вниз по левому ряду и вверх по правому.

- Вывод 16, VCC — 5V Nano, питание
- Вывод 8, GND — GND Nano, питание
- Вывод 4, D0 — D2, выход Nano
- Вывод 5, D1 — D3, выход Nano
- Вывод 6, D2 — D4, выход Nano
- Вывод 7, D3 — D5, выход Nano
- Вывод 2, J — D6, выход Nano
- Вывод 3, K — D7, выход Nano
- Вывод 9, PE — D8, выход Nano
- Вывод 1, MR — D9, выход Nano
- Вывод 10, CP — D10, выход Nano
- Вывод 15, Q0 — D11, вход Nano
- Вывод 14, Q1 — D12, вход Nano
- Вывод 13, Q2 — D13, вход Nano
- Вывод 12, Q3 — A0, вход Nano
- Вывод 11, nQ3 — A1, вход Nano

D13 подключён к `Q2`, поэтому светодиод платы повторяет этот разряд.

`MR` — асинхронный сброс активным низким уровнем: `Q0`–`Q3` становятся 0, `nQ3` становится 1, такт при этом не нужен. Пока `MR` низкий, фронт `CP` регистр не загружает. После отпускания `MR` нули держатся до следующего фронта.

`PE` в LOW включает параллельную загрузку, но только по фронту `CP`: `Q0`–`Q3` принимают `D0`–`D3`, а `nQ3` становится инверсией `D3`. Без фронта смена `D0`–`D3` выходы не меняет. `PE` в HIGH на том же фронте сдвигает слово в сторону `Q3`: новый `Q1` равен старому `Q0`, `Q2` старому `Q1`, `Q3` старому `Q2`. Новый `Q0` задаёт пара `J` и `K`. Вывод `K` активный низкий: оба высоких устанавливают `Q0`, оба низких сбрасывают его, `J` высокий при `K` низком инвертирует `Q0`, `J` низкий при `K` высоком оставляет `Q0`. Если `J` и `K` соединить, пара работает как вход D.

Скетч `ttl74195_nano/ttl74195_nano.ino` после сброса ждёт любой символ из Serial Monitor и проверяет сброс, загрузку 0–15, удержание без фронта, сдвиг при связанных `J` и `K`, четыре режима JK и перекрытие фронта сбросом. Успех — последняя строка `RESULT PASS`. Первое расхождение печатается как `RESULT FAIL` и дальше не затирается. Повторный символ запускает проверку ещё раз.
