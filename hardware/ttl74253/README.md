# Стенд Arduino Nano и 74HC253

Временная проверка физической микросхемы. Перед merge request этот каталог удаляется.

Цоколёвка — Nexperia 74HC253 и TI SN74HC253. У DIP-16, SO16 и TSSOP16 номера выводов совпадают: вывод 8 это GND, вывод 16 это VCC. Если корпус не DIP, для макетной платы нужен переходник. Перед подачей питания сверить маркировку и убедиться, что вывод 8 соединён с GND.

Nano работает от 5 В. D0 и D1 заняты Serial (115200) и к микросхеме не подключаются. A6 и A7 у ATmega328P только аналоговые, как цифровые их использовать нельзя. Между выводами 16 и 8, рядом с корпусом, поставить конденсатор 100 нФ. Входы CMOS нельзя оставлять висящими: все двенадцать приходят с Nano.

Между каждым выходом `1Y` и `2Y` и входом Nano стоит резистор 470 Ом. Скетч на короткое время прижимает свой вход к земле, чтобы отличить высокий уровень от третьего состояния, и резистор ограничивает ток этого опроса.

Точка или выемка на корпусе отмечает сторону вывода 1. Ниже нумерация сверху, от выемки вниз по левому ряду и вверх по правому.

- Вывод 1, n1OE — D2, выход Nano
- Вывод 2, S1 — D3, выход Nano
- Вывод 3, 1I3 — D4, выход Nano
- Вывод 4, 1I2 — D5, выход Nano
- Вывод 5, 1I1 — D6, выход Nano
- Вывод 6, 1I0 — D7, выход Nano
- Вывод 7, 1Y — D12, вход Nano, через 470 Ом
- Вывод 8, GND — GND Nano, питание
- Вывод 9, 2Y — D13, вход Nano, через 470 Ом
- Вывод 10, 2I0 — D8, выход Nano
- Вывод 11, 2I1 — D9, выход Nano
- Вывод 12, 2I2 — D10, выход Nano
- Вывод 13, 2I3 — D11, выход Nano
- Вывод 14, S0 — A0, выход Nano
- Вывод 15, n2OE — A1, выход Nano
- Вывод 16, VCC — 5V Nano, питание

D13 подключён к `2Y`, поэтому светодиод платы повторяет второй выход, пока он не в третьем состоянии.

`n1OE` и `n2OE` независимы. HIGH отпускает выход своего канала в Z. LOW пропускает выбранный вход без инверсии. Общие `S1` (старший) и `S0` (младший) задают адрес: 00 это `I0`, 01 это `I1`, 10 это `I2`, 11 это `I3`. Невыбранные входы на выход не влияют.

Опрос выхода: сначала чтение с внутренней подтяжкой к питанию, затем краткий разряд входа Nano в LOW и чтение без подтяжки. Оба нуля — выход прижат к 0, обе единицы — к 1, единица затем ноль — Z.

Скетч `ttl74253_nano/ttl74253_nano.ino` после сброса ждёт любой символ из Serial Monitor. Он проверяет Z при обоих разрешениях в HIGH, Z только у отпущенного канала, пока второй передаёт выбранный вход, и прохождение выбранного входа обоими каналами при обоих разрешениях в LOW для всех четырёх адресов. Успех — последняя строка `RESULT PASS`. Первое расхождение печатается как `RESULT FAIL` и дальше не затирается. Повторный символ запускает проверку ещё раз.
