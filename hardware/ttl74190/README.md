# Стенд Arduino Nano и 74HC190

Временная проверка физической микросхемы. Перед merge request этот каталог удаляется.

Цоколёвка — TI CD74HC190 и Philips/Nexperia 74HC190. У DIP-16, SO16 и TSSOP16 номера выводов совпадают: вывод 8 это GND, вывод 16 это VCC. Если корпус не DIP, для макетной платы нужен переходник. Перед подачей питания сверить маркировку и убедиться, что вывод 8 соединён с GND.

Nano работает от 5 В. D0 и D1 заняты Serial (115200) и к микросхеме не подключаются. A6 и A7 у ATmega328P только аналоговые, как цифровые их использовать нельзя. Между выводами 16 и 8, рядом с корпусом, поставить конденсатор 100 нФ. Внешние подтяжки не нужны: входы CMOS нельзя оставлять висящими, все они приходят с Nano, выходы двухтактные.

Точка или выемка на корпусе отмечает сторону вывода 1. Ниже нумерация сверху, от выемки вниз по левому ряду и вверх по правому.

- Вывод 16, VCC — 5V Nano, питание
- Вывод 8, GND — GND Nano, питание
- Вывод 15, D0 — D2, выход Nano
- Вывод 1, D1 — D3, выход Nano
- Вывод 10, D2 — D4, выход Nano
- Вывод 9, D3 — D5, выход Nano
- Вывод 4, nCE — D6, выход Nano
- Вывод 5, D/U — D7, выход Nano
- Вывод 11, nPL — D8, выход Nano
- Вывод 14, CP — D9, выход Nano
- Вывод 3, Q0 — D10, вход Nano
- Вывод 2, Q1 — D11, вход Nano
- Вывод 6, Q2 — D12, вход Nano
- Вывод 7, Q3 — D13, вход Nano
- Вывод 12, TC — A0, вход Nano
- Вывод 13, nRC — A1, вход Nano

D13 подключён к `Q3`, поэтому светодиод платы повторяет старший бит счётчика.

`nPL` — асинхронная параллельная загрузка активным низким уровнем. Пока он в LOW, `Q0`–`Q3` повторяют `D0`–`D3` и такт не считает. `D/U` в LOW считает вверх, в HIGH — вниз. Счёт идёт по фронту `CP`, только если `nPL` высокий и `nCE` низкий. `TC` высокий лишь в коде 9 при счёте вверх или в коде 0 при счёте вниз, и только пока `nCE` низкий. `nRC` низкий только когда `TC` высокий и `CP` низкий.

Нелегальные коды 10–15 взяты с Figure 3 даташита TI. Вверх каждый из них за один такт попадает в 0–9. Вниз 11 переходит в 10 и только следующим тактом в 9.

Скетч `ttl74190_nano/ttl74190_nano.ino` после сброса ждёт любой символ из Serial Monitor и проверяет загрузку 0–15, один шаг вверх и вниз из каждого кода, `TC` и `nRC`, запрет по `nCE` и перекрытие фронта загрузкой. Успех — последняя строка `RESULT PASS`. Первое расхождение печатается как `RESULT FAIL` и дальше не затирается. Повторный символ запускает проверку ещё раз.
