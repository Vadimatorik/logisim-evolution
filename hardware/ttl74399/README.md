# Стенд Arduino Nano и 74HC399

Временная проверка физической микросхемы. Перед merge request этот каталог удаляется.

Цоколёвка — TI SN74LS399 и совместимые Fairchild 74AC399 и 74F399, корпус DIP-16. Отдельного даташита Nexperia 74HC399 нет, поэтому перед подачей питания сверить маркировку с этой таблицей. Вывод 8 это GND, вывод 16 это VCC. Низкий `S` выбирает порт 0 (`I0a I0b I0c I0d`), высокий — порт 1 (`I1a I1b I1c I1d`). Выбранное слово записывается в `Qa Qb Qc Qd` по фронту `CP` (низкий к высокому). По спаду и без фронта выходы не меняются. Асинхронного сброса нет, поэтому до первого фронта состояние выходов неизвестно: скетч начинает с захвата известного слова. Это не 74HC298: у 298 другой цоколёвка и запись по спаду.

Nano работает от 5 В. D0 и D1 заняты Serial (115200) и к микросхеме не подключаются. A6 и A7 у ATmega328P только аналоговые, как цифровые их использовать нельзя. D13 не используется. Между выводами 16 и 8, рядом с корпусом, поставить конденсатор 100 нФ. Внешние подтяжки не нужны: входы CMOS нельзя оставлять висящими, все они приходят с Nano, выходы двухтактные. До старта проверки скетч держит `CP` и `S` низкими, а входы данных — в низком уровне.

Точка или выемка на корпусе отмечает сторону вывода 1. Ниже нумерация сверху, от выемки вниз по левому ряду и вверх по правому.

- Вывод 16, VCC — 5V Nano, питание
- Вывод 8, GND — GND Nano, питание
- Вывод 1, S — D2, выход Nano
- Вывод 2, Qa — D12, вход Nano
- Вывод 3, I0a — D4, выход Nano
- Вывод 4, I1a — D5, выход Nano
- Вывод 5, I1b — D7, выход Nano
- Вывод 6, I0b — D6, выход Nano
- Вывод 7, Qb — A0, вход Nano
- Вывод 9, CP — D3, выход Nano
- Вывод 10, Qc — A1, вход Nano
- Вывод 11, I0c — D8, выход Nano
- Вывод 12, I1c — D9, выход Nano
- Вывод 13, I1d — D11, выход Nano
- Вывод 14, I0d — D10, выход Nano
- Вывод 15, Qd — A2, вход Nano

Скетч `ttl74399_nano/ttl74399_nano.ino` после сброса ждёт любой символ из Serial Monitor. Он проверяет захват кодов 0–15 из порта 0 при низком `S` и из порта 1 при высоком `S` (другой порт при этом инвертирован), удержание при смене данных без фронта, отсутствие записи по спаду и то, что `S` сэмплируется только по фронту. Бит 0 кода — это `a`/`Qa`, бит 3 — `d`/`Qd`. Успех — последняя строка `RESULT PASS`. Первое расхождение печатается как `RESULT FAIL` и дальше не затирается. Повторный символ запускает проверку ещё раз.
