# Стенд Arduino Nano и 74HC298

Временная проверка физической микросхемы. Перед merge request этот каталог удаляется.

Цоколёвка — Hitachi HD74HC298 и совместимый ON SN74LS298, корпус DIP-16. Вывод 8 это GND, вывод 16 это VCC. Низкий `WS` выбирает слово 1 (`A1 B1 C1 D1`), высокий — слово 2 (`A2 B2 C2 D2`). Выбранное слово записывается в `QA QB QC QD` по спаду `CLK`. Пока `CLK` высокий или на подъёме, выходы не меняются. Асинхронного сброса нет, поэтому до первого спада состояние выходов неизвестно: скетч начинает с захвата известного слова.

Nano работает от 5 В. D0 и D1 заняты Serial (115200) и к микросхеме не подключаются. A6 и A7 у ATmega328P только аналоговые, как цифровые их использовать нельзя. Между выводами 16 и 8, рядом с корпусом, поставить конденсатор 100 нФ. Внешние подтяжки не нужны: входы CMOS нельзя оставлять висящими, все они приходят с Nano, выходы двухтактные. До старта проверки скетч держит `CLK` и `WS` низкими, а входы данных — в низком уровне.

Точка или выемка на корпусе отмечает сторону вывода 1. Ниже нумерация сверху, от выемки вниз по левому ряду и вверх по правому.

- Вывод 16, VCC — 5V Nano, питание
- Вывод 8, GND — GND Nano, питание
- Вывод 1, B2 — D2, выход Nano
- Вывод 2, A2 — D3, выход Nano
- Вывод 3, A1 — D4, выход Nano
- Вывод 4, B1 — D5, выход Nano
- Вывод 5, C2 — D6, выход Nano
- Вывод 6, D2 — D7, выход Nano
- Вывод 7, D1 — D8, выход Nano
- Вывод 9, C1 — D9, выход Nano
- Вывод 10, WS — D10, выход Nano
- Вывод 11, CLK — D11, выход Nano
- Вывод 12, QD — D12, вход Nano
- Вывод 13, QC — A0, вход Nano
- Вывод 14, QB — A1, вход Nano
- Вывод 15, QA — A2, вход Nano

Скетч `ttl74298_nano/ttl74298_nano.ino` после сброса ждёт любой символ из Serial Monitor. Он проверяет захват кодов 0–15 из слова 1 при низком `WS` и из слова 2 при высоком `WS` (второе слово при этом инвертировано), отсутствие реакции на подъём и на смену данных без спада. Бит 0 кода — это `A`/`QA`, бит 3 — `D`/`QD`. Успех — последняя строка `RESULT PASS`. Первое расхождение печатается как `RESULT FAIL` и дальше не затирается. Повторный символ запускает проверку ещё раз.
